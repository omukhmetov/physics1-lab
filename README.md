# Physics 1 Visual Lab

Interactive companion to the textbook *Physics 1: Mechanics* (O. Mukhmetov).
Each INTERACTIVE box in the book links to an instrument on this site, for example
`https://omukhmetov.github.io/physics1-lab/#ch1-addition`.

The site is a single file, `index.html`, with no build step.
